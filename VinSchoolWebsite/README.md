## Running the project locally

You need to open **2 terminals** to run both backend and frontend.

---

### 🔹 1 Start Backend

In the first terminal:

```bash
cd back-end-chatbot
npm install
npm run dev
```

### 🔹 2 Start Backend
```bash
cd front-end-chatbot
npm install
npm run dev
```
